Sổ Tay Công Thức Toán (Lớp 3 - 5)

1. Chu Vi & Diện Tích Hình Học Phẳng

• Hình vuông: $P = a \times 4$, $S = a \times a$

• Hình chữ nhật: $P = (a + b) \times 2$, $S = a \times b$

• Hình tam giác: $S = (a \times h) : 2$

• Hình thang: $S = (a + b) \times h : 2$

• Hình bình hành: $S = a \times h$

• Hình thoi: $S = (m \times n) : 2$

• Hình tròn: $C = d \times 3,14 = r \times 2 \times 3,14$, $S = r \times r \times 3,14$

2. Diện Tích & Thể Tích Hình Khối 3D

• Hình lập phương: $S_{xq} = a \times a \times 4$, $S_{tp} = a \times a \times 6$, $V = a \times a \times a$

• Hình hộp chữ nhật: $S_{xq} = (a + b) \times 2 \times h$, $S_{tp} = S_{xq} + 2 \times a \times b$, $V = a \times b \times h$

3. Toán Chuyển Động Học (Lớp 5)

• Công thức cơ bản: $s = v \times t$, $v = s : t$, $t = s : v$

• Ngược chiều (Gặp nhau): $t_{\text{gặp}} = s : (v_1 + v_2)$

• Cùng chiều (Đuổi kịp): $t_{\text{đuổi}} = s : (v_1 - v_2)$

• Dòng nước: $v_{\text{xuôi}} = v_{\text{thực}} + v_{\text{nước}}$, $v_{\text{ngược}} = v_{\text{thực}} - v_{\text{nước}}$

4. Phân Số, Tỉ Số & Phần Trăm

• Phép chia phân số: Lấy phân số thứ nhất nhân đảo ngược phân số thứ hai.

• Tổng - Tỉ: Giá trị 1 phần = Tổng : Tổng số phần bằng nhau.

• Hiệu - Tỉ: Giá trị 1 phần = Hiệu : Hiệu số phần bằng nhau.

• Tỉ số phần trăm: Tỉ số $\%$ của $A$ và $B$ là $(A : B) \times 100\%$.
